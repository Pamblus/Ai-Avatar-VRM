# AI-Avatar-VRM

Веб-приложение для интерактивного **VRM-аватара** с LLM-чатом и BVH-анимациями.
Ты пишешь сообщение — нейросеть отвечает и **управляет телом модели** через
специальные теги: позы, повороты, мимика, эмоции, готовые BVH-анимации.

## ✨ Что это

**AI-Avatar-VRM** — это связка из трёх частей:

1. **Фронтенд** (`index.html`) — рендерит VRM-модель через Three.js, проигрывает
   BVH-анимации, показывает чат и панель анимаций.
2. **Бэкенд** (`main.py`) — принимает сообщения, отправляет их в LLM
   (OpenRouter), парсит ответ с тегами в структурированные шаги.
3. **Промпт** (`prompts.txt`) — характер аватара и правила поведения LLM.

LLM возвращает текст с тегами, бэкенд превращает их в JSON-шаги, а фронтенд
исполняет их по очереди — аватар двигается, говорит и меняет мимику.

## 🚀 Возможности

### Движение
- **Готовые BVH-анимации** — танцы, позы, жесты (подключаются из папки)
- **Ручные позы** — покадровое управление всеми костями через JSON
- **Трансформ модели** — сдвиг и поворот всего аватара в пространстве
- **Циклы** — повтор блока шагов N раз
- **Паузы** — точная задержка между действиями

### Мимика
- Морфы лица: `happy`, `angry`, `relaxed`, `blink`, `aa`, `ih`, `ou`, `ee`, `oh`
- Автоматическое моргание
- Эмоциональные пресеты: `wave`, `nod`, `joy`, `kneel`, `lie`, `blink`, `neutral`

### Чат
- Общение с LLM через OpenRouter
- История сообщений в контексте
- Индикатор набора текста
- Очередь шагов — анимации выполняются последовательно

### Интерфейс
- Адаптивный дизайн (мобильные + десктоп)
- Панель анимаций с поиском
- Управление плеером: play / pause / stop / скорость
- Лепестки сакуры, искры и градиентный фон
- Свайпы для сворачивания/разворачивания чата

### BVH-ретаргетинг
- Автоматическая подгонка BVH-скелета под кости VRM
- Точное совпадение по 22 humanoid-костям
- Кэширование готового клипа для быстрого повтора

## 🧠 Как работает управление

LLM отвечает текстом, в котором есть **речевая часть** и **теги действий**.
Пример ответа:

```

Привет! Сейчас покажу ✨
[emote dur=1.5]wave[/emote]
[face happy=0.8][/face]

```

Всё, что **вне тегов** — это речь, попадает в чат.
Всё, что **внутри тегов** — команды для аватара.

### Поддерживаемые теги

| Тег | Что делает |
|---|---|
| `[pose dur=0.5 hold=1.0]{...}[/pose]` | Поза, все кости параллельно |
| `[body y=0.3 rx=-1.57]...[/body]` | Сдвиг/поворот всей модели |
| `[face happy=0.8][/face]` | Морфы лица (0..1) |
| `[emote dur=1.6]wave[/emote]` | Эмоциональный пресет |
| `[wait]0.5[/wait]` | Пауза в секундах |
| `[loop count=4]...[/loop]` | Повтор блока N раз |
| `[bvh]dance.bvh[/bvh]` | Запуск BVH-анимации |
| `[freeze]` | Застыть в текущей позе |
| `[stop]` | Вернуться в нейтраль |

## 📦 Установка

### Требования
- Python 3.10+
- Токен [OpenRouter](https://openrouter.ai/)
- VRM-модель (`character.vrm`)
- BVH-анимации (папка с `.bvh`) прописать путь до файлов в main.py

### Шаги

Настройка .env

```env
OPENROUTER_API_KEY=sk-or-v1-9990
OPENROUTER_SITE_URL=https://termux.local
OPENROUTER_SITE_NAME=AI-Avatar-VRM
```

Запуск

```bash
python main.py
```

Открой в браузере:

```
http://localhost:8000
```

🔌 API

POST /api/chat

Отправка сообщения и получение ответа с шагами.

Request:

```json
{
  "messages": [
    {"role": "user", "content": "станцуй"}
  ]
}
```

Response:

```json
{
  "say": "Сейчас покажу! 💃",
  "steps": [
    {"bvh": "dance.bvh"}
  ]
}
```

GET /api/health

Проверка состояния сервера.

GET /api/animations

Список доступных BVH-файлов.

POST /api/animations/reload

Сброс кэша списка анимаций.
