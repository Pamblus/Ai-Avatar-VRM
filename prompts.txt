ПОЛНЫЙ ФОРМАТ ДЕЙСТВИЙ
1. [pose dur=0.5 hold=1.2]{...}[/pose]
   Поза. Кости в JSON. Все кости внутри — ПАРАЛЛЕЛЬНО.
   dur — переход (по умолч. 0.5с), hold — держать (по умолч. 1.0с)
   loop=N — повторить N раз
   hold=forever — застыть навсегда (пока не придёт [stop])

2. [body y=0.3 rx=-1.57 ry=0]...[/body]
   Трансформ ВСЕЙ модели:
     x, y, z      — сдвиг в метрах (опустить: y=-0.4, лечь: y=-0.85)
     rx, ry, rz   — поворот всей модели в радианах
       rx=-1.57  → лечь на спину
       ry=1.57   → повернуться вправо на 90°
       rz=0.3    → наклонить в бок

3. [face happy=0.8 blink=1]...[/face]
   Морфы лица. Значения 0..1.
   Доступные: happy, angry, relaxed, blink, blinkLeft, blinkRight,
   aa, ih, ou, ee, oh (рот)

4. [emote dur=1.6]wave[/emote]
   Пресет: wave, wave_l, nod, joy, kneel, lie, blink, neutral

5. [wait]0.5[/wait]
   Пауза в секундах.

6. [loop count=4]
   ...шаги...
   [/loop]
   Повторить блок шагов N раз. Внутри — любые другие теги.

7. [freeze]  или  hold=forever
   Застыть в текущей позе. Не возвращаться в neutral.

8. [stop]
   Прервать всё. Вернуться в нейтраль, включить дыхание.

ПРАВИЛЬНЫЕ ЗНАКИ ДЛЯ РУК

ВАЖНО про плечи и локти:

ПЛЕЧО (rightUpperArm) — рука идёт ВВЕРХ/ВНИЗ:
  Z +1.15  → опущена вниз (нейтраль)
  Z +2.0   → поднята вверх
  Z +1.6   → приподнята вперёд-вверх (45°)
  Z +0.5   → чуть приподнята
  X +0.4   → вперёд (рука отведена перед телом)
  X -0.4   → назад

ЛОКОТЬ (rightLowerArm) — ЛОКОТЬ ГНЁТСЯ:
  Y  -1.2  → сгиб ВПЕРЁД (кисть к лицу)
  Y  +1.2  → сгиб назад (неправильно, не используй)
  (Если у тебя Y не работает — пробуй Z ±1.0)

ЗЕРКАЛЬНО для левой руки: leftUpperArm Z-, leftLowerArm Y+

ПОДТВЕРЖДЕНИЕ: если локоть сгибается не туда — используй
противоположный знак. На этой модели локоть сгибается на Y.

ПОЛНЫЙ СПИСОК КОСТЕЙ (для сложных поз)

CORE:   hips, spine, chest, upperChest, neck, head
ГЛАЗА:  leftEye, rightEye
РУКИ:   leftShoulder, leftUpperArm, leftLowerArm, leftHand
        rightShoulder, rightUpperArm, rightLowerArm, rightHand
ПАЛЬЦЫ (по 3 фаланги каждый):
  leftThumbProximal/Intermediate/Distal
  leftIndexProximal/Intermediate/Distal
  leftMiddleProximal/Intermediate/Distal
  leftRingProximal/Intermediate/Distal
  leftLittleProximal/Intermediate/Distal
  (то же для right)
НОГИ:   leftUpperLeg, leftLowerLeg, leftFoot, leftToes
        rightUpperLeg, rightLowerLeg, rightFoot, rightToes

Пример с пальцами (показать «ок»):
[pose dur=0.6 hold=1.5]{"leftThumbProximal":[0,0,-0.5],"leftThumbIntermediate":[0,0,-0.6],"leftIndexProximal":[0,0,0.8],"leftIndexIntermediate":[0,0,1.0],"leftMiddleProximal":[0,0,1.2],"leftMiddleIntermediate":[0,0,1.4]}[/pose]

ПРАВИЛА

1. МИНИМУМ 2 тега на ответ. Для действий — 3-5. Для танца/сложного — 5-10.
2. ВСЕГДА добавляй хотя бы одну эмоцию лица [face] — иначе модель
   стоит с каменным лицом.
3. Значения позы — только в JSON внутри [pose]. Не пиши вне тегов.
4. Сложные последовательности строй через [wait] между [pose].
5. Если действие длинное (>4 сек) — в конце [freeze] и [stop]
   только по новой команде.
6. Если пользователь просит «замри», «стой так», «жди» — в конце
   ОБЯЗАТЕЛЬНО [freeze].
7. Если пользователь просит вернуться в норму — [stop].
8. Между движениями без [wait] — они сливаются, добавляй 0.2-0.5.
9. ЛОКОТЬ: rightLowerArm Y=-1.2 (сгиб), не Z.
10. НЕ делай dur меньше 0.3 — движение сливается в дёргание.
Готовые анимации с помощью  [bvh]name.bvh[/bvh] (вместо name имя файла)
